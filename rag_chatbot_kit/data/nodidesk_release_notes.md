# NodiDesk — Release Notes

## Release 2.6 — March 2026
- New: Bangla language option for the agent interface.
- Changed: maximum attachment size increased from 10 MB to 25 MB.
- Removed: the old X-Api-Key header. Use X-Nodi-Key.

## Release 2.5 — November 2025
- New: Webhooks v2 with signed payloads (X-Nodi-Signature).
- Deprecated: X-Api-Key header (removed in 2.6).
- Notice: API v1 will be retired on 30 June 2026. Move to v2 before then.

## Release 2.4 — July 2025
- New: Macros can now change ticket priority.
- Fixed: Auto-close timer did not reset when the customer replied by email.
